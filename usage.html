动小学 · 使用说明

打开网站

将完整 ZIP 解压到一个文件夹。Windows可双击 preview.cmd（优先调用已有Codex运行环境），启动本机教学服务后打开 http://127.0.0.1:8771/。需要纯静态预览时可运行 python start_local.py，打开8765端口；此方式没有服务器采集。也可把完整文件夹放到静态网站服务器；保持目录结构。不要双击 HTML 直接打开，模型需要通过 HTTP 读取。

本包不包含学校认证或已接通的外部AI服务；附带本机学习过程采集与教师看板，不作为成绩认证系统。首页姓名、学号和教师姓名仅用于课堂登记；任课教师填写“张积众”。

课堂操作

  1. 首页登记后进入13项实验课程，或选择骨骼拼接、肌肉安放。
  2. 静态图谱支持结构筛选与视角观察；拼接练习保留引导归位、定向拼接与左右混合。
  3. 四类动态图形是机制示意，注意每页的观察范围。
  4. 足底压力交互探究先说明为什么测，再按预测、找证据、解释完成任务。拖动三维实验台旋转，滚轮缩放，点击测点查看原值；也可展开二维核对。标记左足25/50帧，比较最高值、总和与单脚压力中心。通道值和来源坐标没有换算为物理单位；柱高是显示映射。
  5. 回到首页“本机记录”，导出 HTML 或 JSON，自行提交教师。

记录保存在当前浏览器；清理浏览器数据会删除记录。共用设备完成后请切换学生。本版记录与旧版分开保存。

素材和教学范围

BodyParts3D 静态骨肌素材用于结构识别与空间关系学习。图谱位置不是患者坐标；拼接得分不是临床技能认证。机制示意图不计算肌肉动力学，不代表真实步态。足底压力模块单独展示公开研究数据，不能据此诊断个人足弓、步态或计算未经标定的物理压力。

数字助教提供固定导学内容，采用原创图形形象。点击“朗读”才调用设备语音；默认不朗读。

教师审查记录 · 资源检查

足踝虚拟诊室与教师看板

完整解压后双击 preview.cmd，或运行 python serve_lab.py。本机学生入口为 http://127.0.0.1:8771/；教师专用链接及访问码在启动窗口显示。服务仅绑定本机，访问码用于保护本机记录，不等同学校身份认证。

诊室采用原创虚构教学病例与AI生成场景立绘，患者图像不是三维动作或实测诊断资料。问诊与检查记录提交到同源本机服务；断开服务时在浏览器保留待传队列，可重试与导出。教师看板显示真实收到的记录，不预填模拟学生数据。

python start_local.py 仍可用于纯静态预览；此方式不提供服务器采集。DeepSeek需另在服务环境配置凭据，未配置时使用固定病例问答。没有真实API连接测试前，不宣称已接通在线模型。
