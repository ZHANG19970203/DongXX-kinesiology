# 足踝虚拟诊室 v23 · 三维接诊与可追溯学习

本次发布：2026-10-26。用于课程试用、教师审查与继续迁移；未经临床运动学验证，不能视为已通过国家申报验收的成品。

## 使用
当前学生入口 http://127.0.0.1:8784/ 。登记后直接进入三维诊室；点击“开始接诊”才弹出用户提供的导入视频。其余视频随检查节点出现并返回场景。右上角“…”提供总项目导引、跳步、记录和深入学习。

在新电脑运行 python serve_lab.py --port 8784 --data-dir 网站目录之外的资料目录；不要仅双击HTML或用静态服务器代替学习记录服务。现有本机启动器保留旧课堂数据库和AI设置。

## 本次变化
1. 新科幻跑步人体登录视觉；学生、教师入口分开。
2. 诊室作为主入口；SOAP任务册保留为备学资源。
3. 足弓、关节、肌肉改用已有BodyParts3D/Somakine三维网格，保留起止点说明、旋转缩放和有限轴面驱动。
4. 静态COP改为同尺度、同时间的两组逐点轨迹，旁边三维人物提供站立情境；步态使用诊室人物替代火柴人，COM曲线注明为独立教学函数。
5. A与P之前弹出纸质证据清单，区分到访、完成操作、已阅虚构查体卡、未做项目。关闭清单不会自动越过评定；确认后才继续。
6. 动小助使用与诊室相同的男性治疗师骨架角色，有持续细微姿态动作；概念学习按节点提示、可选展开。
7. 教师新增学生档案页，显示时间、模块、操作、原始讨论、反馈与后测情况；支持完整JSON与汇总CSV导出。提问后的“已理解/还需深入/仍有疑问”为学生自评，不能替代成绩。

## 教师入口与数据
教师只填写姓名，不填学生姓名、学号、任课教师。首次使用本机专用“教师姓名登录_仅本机.html”，它带有本次启动凭据；不放进公开ZIP。姓名不是身份认证，普通学生不能仅填写教师姓名获取全班记录。已有授权的同一浏览器标签可从首页教师入口进入。重启后使用新生成的专用入口。

当前数据库：D:/CodexRuntime/soap-v19/classroom-data/learning.sqlite3 。AI配置也保留在该私有数据目录，未进入交付ZIP。该数据库为持久本机存储，尚未部署云端。教师完整JSON导出是可提取业务档案；恢复服务时须备份整个私有目录（建议停服复制，运行中SQLite应使用backup接口），不要只复制网站ZIP。

有效时间是页面可见、最近120秒有点击/按键/滚轮活动的估计；10秒采样，切后台停计。同一学生重叠时段按并集计，不把多个标签累计成双倍。历史版本未采时段不补造。掉线事件保留浏览器队列，恢复页面后继续同步；关闭浏览器前应看同步状态。永久断网且清除浏览器资料前未同步的记录无法由服务器恢复。

目标达成率仍由8个知识目标、16道正式后测题计算；每目标两题均正确才达成。浏览、看视频、读病例卡不加分。开放分析与临床操作需要教师评阅。
