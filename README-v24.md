## 问答与数据导出

已配置的服务为硅基流动 API，模型 `deepseek-ai/DeepSeek-V4.1-Flash`，不是读取个人DeepSeek消费端聊天历史。秘钥不随网站分发。问题在获得学生发送同意后，连同必要课程材料和最近6轮成功问答发送到该服务。每个主题最多12轮，同一自报身份每天最多30次（北京时间），失败与不确定状态也保留，不伪造答案。

检索对象是本项目的小型课程资料，不是图片示例中的数万条资料，也不是实时网页搜索。展示的检索参考不等于模型实际逐条引用；重要知识仍需核对原文和教师指导。

Excel包含8个工作表：学生汇总、学习会话、模块用时、全部操作、问答记录（含参考和教师点评）、知识后测、使用反馈、统计说明。原始JSON也可导出。有效用时指页面可见且最近120秒有输入的区间估计，重叠区间取并集；不能推断注意力。知识后测8目标各2题，全部正确才算该目标达成，不把访问、聊天或播放当成通过。13实验记录不冒充足踝后测或临床技能成绩。旧版未采集的数据不补造。

Excel由 `@oai/artifact-tool` 生成。当前机器使用已安装的Node运行环境。另机部署时配置 `DXX_NODE_EXE` 和 `DXX_NODE_PACKAGES`；密钥通过教师后台重新配置。标准启动命令和恢复方法见 `DEPLOY_GUIDE.html`。
