# 第二、三幕：踝足活动度与肌力方法审查

本稿供教师审核和实施记录使用。角色为男治疗师林治疗师、女患者陈女士。当前可完成的是**解剖、动作和检查方法练习**；未经患者配准的骨网格、人物关节和按钮不能生成陈女士的实测ROM、MMT等级、关节力矩或肌电信号。

## 需要修改的临床表达

| 原稿中需避免的说法 | 建议表达与教学范围 |
|---|---|
| “踝关节是三个轴、三个自由度的滑车关节” | 区分单个距小腿关节与踝足复合体。距小腿关节按基础解剖归为滑车/铰链型，主要参与背屈、跖屈；距下与其他跗骨间关节参与内外翻、旋前旋后等复合运动。三面三轴用于描述整个踝足的空间运动，不代表三个独立、互不耦合的距小腿转轴。 |
| “距下关节就是一个独立转轴，内外翻仅在额状面发生” | 距下由距骨与跟骨间关节面构成。基础分类常列为跗骨间滑膜平面关节，功能运动则围绕斜轴耦合。教具可显示额状面内外翻分量，同时说明实际旋前/旋后包含多个平面、多个关节。不要把它讲成单纯车轴关节或球窝关节。 |
| “三条彩轴就是患者的真实运动轴” | 彩轴是教学参考轴。真实轴有倾斜、位置变化与个体差异；静态网格没有完成患者关节配准，不能用参考轴声称精确关节运动学。 |
| “右背屈11°，正常至少15°，所以诊断某组织异常” | 当前系统没有患者实测角度，不能说已经从角色测得11°。若另用该数值，只能明确标为既有虚构病例资料并交代方法；日后加入合法测量还需记录主动/被动、负重条件、膝角、足位、标志、单位、终点与症状。11°和≥15°不能脱离方法与人群作万能阈值，也不能单独定位组织病变。 |
| “患者俯卧，依次测完所有踝足肌力” | 按目标肌和分级方案选择体位。背屈常用坐位；跖屈可依方案用非负重检查并在耐受时补充有保护的站立提踵；内翻、外翻另需足位与近端固定。不能把不同体位或不同量表的数字混用。 |
| “外翻肌力4级，所以外翻力矩不足、激活延迟” | MMT是按规定条件的临床顺序分级。不能换算成力量百分比或N·m，更不能推出步行中的激活先后。定量力矩需要力及力臂等测量；EMG时序需要实际信号及分析方法。当前页面只记录知识与方法选择。 |

单关节与复合运动的区分以[OpenStax官方教材](https://openstax.org/books/anatomy-and-physiology-2e/pages/9-6-anatomy-of-selected-synovial-joints)为入门依据，在体研究也显示足弓关节参与总体背屈/跖屈，不能把足部整体角度等同距小腿单关节运动。[Lundberg等原始研究](https://pubmed.ncbi.nlm.nih.gov/2731829/)

## 开链、闭链滚滑的可教学说法

先声明固定谁、观察谁。下表是**理想化凹凸接触规则示意**，用于解释相对运动，不能当作已从陈女士身上测得的关节面轨迹，也不能据此自动选择关节松动手法。

| 观察条件 | 背屈 | 跖屈 |
|---|---|---|
| 小腿固定、距骨相对踝穴运动的开链示意 | 距骨前滚、后滑 | 距骨后滚、前滑 |
| 足部固定、观察凹胫骨关节面相对距骨运动的闭链示意 | 胫骨向前滚动/滑动 | 胫骨向后滚动/滑动 |

开链规则可核对[俄克拉荷马大学健康科学中心教学页](https://www.ouhsc.edu/bserdac/dthompso/web/namics/ankle.htm)。闭链重点让学生看懂“足跟落地时小腿向前”，文献描述胫骨关节面在距骨顶上前移。[负重弓步原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3484905/)

不能在没有说明参考骨的情况下，把“距骨后滑”和“胫骨前移”写成两种相反结论。也不把简化凹凸规则机械套到距下各关节面的复杂耦合。当前教具仍以整体旋转说明方向，不伪造软骨接触、滑移毫米数或韧带张力。

## 第二幕：精简对白与任务

林治疗师：“先坐稳，做小幅背屈和跖屈；哪里紧或痛就告诉我。”

陈女士：“右边往上时发紧。”

林治疗师：“坐位和站立的方法不同。统一膝角、足位，再比较左右。发紧不等于骨头错位。”

学生先在授权静态解剖教具辨认胫骨、腓骨、距骨；再核对外踝及量角器两臂参考。随后在病例试次中判断足跟抬起、足外转或左右体位不同是否破坏可比性。通关记录为“对线/方法识别”，不填写ROM角度。

测量方案至少记录：侧别、主动或被动、负重条件、膝屈伸、足位、参考标志、终点、症状以及采用角度还是距离。腓肠肌跨膝，膝角会影响背屈；相关原始研究强调标准化条件，不能把其具体研究膝角推广成所有病人的统一规定。[Baumbach等](https://pubmed.ncbi.nlm.nih.gov/27500825/) 不同量角器、倾角仪和触墙距离也应保留各自单位与误差，不能直接互换。[Konor等](https://pubmed.ncbi.nlm.nih.gov/22666642/)

## 第三幕：肌群、动作与检查条件

林治疗师：“先认清肌群，再按动作选择体位和阻力。”

陈女士：“右边觉得没劲，能直接说肌肉弱吗？”

林治疗师：“还要按方法比较，也要看疼痛和代偿。先把检查条件弄清楚。”

新增纯数据模块为 `case-muscle-v14.js`，导出四项 `MUSCLE_ITEMS`、选择项 `MUSCLE_GROUP_OPTIONS`、五项 `MUSCLE_CONDITIONS`、两幕对白与 `MUSCLE_LESSON`。没有外部资产、API调用或付费制作。

| 匹配动作 | 主要教学肌群 | 条件与解释 |
|---|---|---|
| 踝关节背屈 | 胫骨前肌为代表，其他伸肌协同 | 可采用支撑坐位，避免只伸趾或整腿抬起；不能因一个动作把其他协同肌排除。 |
| 踝关节跖屈 | 腓肠肌、比目鱼肌 | 膝角与负重条件需记录；提踵是有保护的功能任务，结果还受疼痛、体重、平衡和策略影响。 |
| 足内翻 | 胫骨后肌、胫骨前肌 | 踝位改变检查侧重；固定近端，避免髋旋转代偿。 |
| 足外翻 | 腓骨长肌、腓骨短肌 | 统一足位和抵抗条件；不能由手动表现推算定量外翻力矩或肌电潜伏期。 |

这些动作与肌群可核对[UKRI所载MRC原始手册](https://www.ukri.org/wp-content/uploads/2021/12/MRC-011221-AidsToTheExaminationOfThePeripheralNervousSystem.pdf)。[NIH/NIEHS官方流程](https://www.niehs.nih.gov/sites/default/files/research/resources/assets/docs/muscle_grading_and_testing_procedures_508.pdf)也明确不同肌群有不同体位，包含必要的减重条件；其扩展0—10方案不能混入MRC0—5。本版不要求学生在网页上实施抵抗或给患者分级。

可完成的三步任务：

1. 将四个动作匹配到主要肌群。完成表示解剖知识匹配，不表示测得肌肉力量。
2. 核对说明与同意、体位和膝角、固定/阻力、左右同法及症状/疲劳记录。
3. 判断结果边界：目前可解释方法与肌群；不能生成MMT分数、力量百分数、N·m或EMG时序。

MMT与定量测力并非同一测量，相关原始研究不能被拿来替代本病例的个体检查。[Andersen与Jakobsen](https://pubmed.ncbi.nlm.nih.gov/9208265/) 肌电需实际传感器定位、固定和信号条件；肌肉网格亮起或足压颜色不满足这些条件。[SENIAM官方方法](https://www.seniam.org/fixation.htm)

## 当前源码核对与交付边界

当前 `case-flow.js` 的 `alignment.task.measurePatientAngle` 为false；学生点击外踝、固定臂和移动臂，是对线标志确认。`learning-ui.js`只呈现参考卡片、确认按钮与解剖窗；没有在患者身上配准量角器，也没有读取患者骨标点和临床角度。应继续保留这一区别。

骨骼/肌肉网格可以帮助观察位置和动作方向，但没有可靠关节配准及接触数据时，不把它们作为真实肌肉变形、受力或精确关节滚滑。MMT幕以已能实现的知识和方法任务交付，未完成的患者抵抗、触诊和临床分级留在教师审查记录中，不冒称已经执行。

后续若要实际临床测量，需要由专业教师确认方案，保存方法与标志、测试者和重复试次信息，再判断可比性与误差。本审查是文献和实现边界核对，仍需课程负责人签审，不能视作已完成临床运动学验证。
