## v13新增：足弓比较与高足弓知识拓展

在低足弓病例旁加入正常足弓参考，并提供高足弓独立拓展。陈女士仍因反复右踝扭伤与不稳就诊，主病例没有改为高足弓。

比较保持同任务、体重／合成总载荷设定、步速、相位、足侧与固定色标，先看接触面积和负荷分布，再解释可能意义。正常参考不是健康合格模板。高足弓示意中足接触较少，但仍需承重；不能预设所有高足弓均为外侧COP，也不能凭一个压力印诊断或确定病因。

新增3道短卡问题，每题3选1并给出理由反馈：为什么匹配条件、接触少时负荷如何传递、出现症状或新变化时如何进一步评估。互动用于理解与复盘，不产生临床评分；鞋具、辅助支持和训练不使用人人相同的保证性处方。

内容模块为 `clinic3d/arch-knowledge.js`；来源及使用边界见 `clinic3d/docs/arch-v13-sources.json`，新增专业审查项见 `clinic3d/docs/teacher-review-v13.md`。已通过官网与原始研究摘要核对概念；未复制论文／厂商图像、患者数据，也未新增外部模型或付费媒体。既有BodyParts3D／Somakine静态解剖数据继续按CC BY 4.0保留来源署名。
