# v14 八幕脚本临床与教学核对

日期：2026-10-18。核对范围以第4—8幕为重点；第2—3幕的方法和解剖分类由 `v14-rom-mmt-review.md` 与 `v14-rom-mmt-sources.json` 补充。本文件不将运行成功写成临床准确性认证。

人物保持男性林治疗师与女性陈女士。病史沿用14个月前右踝首次扭伤、之后又有两次扭伤，不照搬新稿中的角色、足侧或时间变化。主诉是反复扭伤、不稳及对不平路面的担心，先问诊和安全判断，再逐步取得活动、力量、足形、步态、负荷及平衡资料。

| 正常步态初始接触后一直背屈，或单凭形态判定某肌延迟 | 常见平地成人步行参考中，足跟接触后的加载反应出现受控跖屈，背屈肌参与控制；之后小腿向前，踝逐步背屈 | 一般运动学知识不等于陈女士实测肌肉激活；压力或肉眼观察不能给出肌电时序 |
| 支撑中期重心降到最低 | 平地步行单支撑中段，全身质心通常较高，可用倒摆理解部分能量交换 | 倒摆是简化模型；坡度、速度、个体和病理情况会改变细节。程序骨盆点仍不是全身COM |
| 末期背屈后“完全锁定”，靠刚性足推进 | 末支撑至预摆阶段由背屈方向转向跖屈推进；足与中跗关节仍有运动，足刚度动态调节 | 活体双平面透视及足内在肌研究不支持简单的停止运动／完全锁死叙述 |
| 正常足应均匀承压，非均匀就是异常 | 足底不同区域的接触与载荷本来就随任务、时刻和个体变化 | 无症状站立原始研究显示区域分布不均；研究数值不直接移作本课程正常阈值 |
| 足跟、第1和第5跖骨头是真实全部承重点 | 三点支撑仅用于辨认结构的简化教学，实际接触分布包括多个区域 | 无症状站立研究不支持把真实载荷等同三个孤立点；不能把中足接触直接称作病变 |
| 正常COP必是固定S形；偏离可直接证明扭伤病因 | COP由当前接触载荷加权得到，只在有效接触时解释；轨迹依任务与个体而变 | 静态COP小范围摆动、足内行走COP和双足总COP要区分；COP不是身体重心 |
| 压力可证明胫后肌延迟、腓骨肌无力或某韧带张力增加 | 足压描述外部接触负荷，不能独立识别某肌激活、肌力或韧带张力 | 需要与相应检查／测量和可靠模型结合；本程序没有肌电采集、校准肌力或韧带应变模型 |
| 睁眼20秒、闭眼8秒，说明本体感受器坏了 | 若使用时间，只能明确标注虚构病例记录并记录终止原因；闭眼变化说明任务条件变了，不能特异定位某种感受器损伤 | 视觉、前庭、体感及运动策略共同参与姿势控制；一次平衡结果不是通路诊断 |
| 天生低足弓→所有动作异常→崴脚的完整致病链 | 把已观察、患者报告和待验证解释分开；不补写天生、家族或组织损伤事实 | 原病例未取得先天足形或确定组织因果证据，不应在结尾突然变成已知 |
| 矫形或训练可彻底解决、保证不再扭伤 | 围绕患者目标选择可耐受方案，同方法复评，依据反应调整；必要时补检查 | 不提供统一处方、固定返场许可或疗效保证 |

## 八幕教学组织

1. 接诊问诊：主诉、病史、安全、个人目标与同意。
2. 踝关节活动度：体位、轴面、对线与方法一致性；不假报程序测量。
3. 肌力：先学方向、支撑、体位与分级含义；当前没有真实施阻动画或测力，不用对白声称已经对患者施加阻力。
4. 坐位到站立足弓：先描述足形随负重变化，再讨论柔韧性和症状。
5. 动态步态：同一时间轴看双侧事件、空间时间参数及一般推进机制。
6. 足底压力与COP：分开站立、行走瞬时帧和非同时峰值合成图。
7. 平衡与感觉整合：先安全低难条件，再讨论睁闭眼；尊重随时停止。
8. 综合与康复：证据—问题—可选方案—同法复评，回到患者目标。

这是8类教学环节，不强行称为7项任务。每幕医患对白精简逐句出现；教师说明默认折叠，选择性展开1—3句，避免满屏同步旁白。动小助只在需要操作时给下一步提示，不替代患者同意。
