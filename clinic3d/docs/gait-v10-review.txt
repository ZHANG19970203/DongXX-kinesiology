步态交互 v10：教师审查记录

一、这个病例能够教什么
用同一条时间轴观察左右足接触、离地与前后落点，把步长、跨步长、步宽、步速、步频、支撑期和摆动期联系起来。右侧设为患侧，左侧设为对侧；数字只用于本病例比较，不能当作慢性踝关节不稳的统一表现或诊断界值。右步长按右足落地命名，不等于右侧支撑时间。

二、编写的参数与一致性
完整周期 1.2 s，右步长 0.48 m，左步长 0.40 m，跨步长 0.88 m，步宽 0.14 m。
平均步速 = 0.88 / 1.2 = 0.733333… m/s；步频 = 2 / 1.2 × 60 = 100 步/min。
右足初始接触为 0%；左足初始接触为 46%；右足离地为 56%；左足于本周期 10% 离地（其初始接触在上周期 46%）。
右侧支撑 56%（0.672 s），摆动 44%（0.528 s）；左侧支撑 64%（0.768 s），摆动 36%（0.432 s）。
双足支撑为 0%–10% 与 46%–56%，合计 20%（0.24 s）。其余为单足支撑，无双足腾空。
右步时间 0.648 s，左步时间 0.552 s，合计一个周期 1.2 s。

三、可视化驱动
人物根节点按 0.88 m/周期前进。右足初始接触位置相对根节点前方 0.26 m；左足下次接触点在同一前进轴上再前进 0.40 m。支撑期足跟参考点固定；摆动期通过平滑插值从上次落点移到下次落点，摆足最大示意抬高 0.055 m。以上是原创演示驱动，不是从真实患者、BodyParts3D静态网格或未经授权的旧动力学链推导而来。角色网格、足底轮廓与关节中心并非临床配准结果；鞋底和各身体部分的接触效果仍需画面审查。

四、关于“重心”
显示骨盆参考点的左右、上下位移，帮助学生观察身体随支撑侧转换而移动。此点的位移曲线为编写的教学示意；它不是整个人体按各体段质量加权得到的全身质心，也不是测得的重心轨迹。未依据此点判断稳定边界、跌倒风险或计算真实机械能。COP是接触力作用位置，不能拿骨盆参考点代替，也不等于全身质心在地面的投影。

五、数据与来源
病例数字为原创教学设定，不是研究数据。本模块只引用原始研究中对时空参数及CoM/CoP的定义，详见 gait-v10-sources.json。未复制论文图片、运动轨迹、模型数据或关节链。需要教师审核的部分包括：病例叙事与参数的匹配、患健侧观察表述、测量条件、步态动画的足跟/足尖接触与肢体保护、以及教学评价题。尚未经过临床运动学验证。

六、执行检查
在项目目录运行 Node docs/gait-v10-selftest.mjs：核对公式、两侧支撑占比、接触事件、无腾空、周期性、支撑期足点固定、摆动连续性、足印步长/步宽/步时间的一致性。数学检查不能代替专业教师对临床动作的审核。
