# v13 足弓比较与高足弓拓展教师审查

日期：2026-10-18。本文件仅新增v13审查项，沿用v12及早期尚未完成的专业审查记录；不把技术运行结果写成临床验证。

主病例仍为陈女士因反复右踝扭伤与不稳就诊，低足弓为相关病例特征。正常足弓是同条件教学参考；高足弓是独立知识拓展，不能在切换图谱后改写陈女士病史或诊断。

## 随身记录用品与对称步态参考

对称步态参考为作者设定的44/44cm步长、双侧60%支撑/40%摆动，保持与病例同周期和步速。应审核时空参数、事件边界、观察者解释，不将其说成正常值范围或由低足弓引起的必然差异。正常参考不继承患者患侧身份；没有分段质量全身COM。

记录夹和笔不用时直接放接诊桌；观察步态和足压时手持，手法检查和平衡保护前回桌。已去除单独记录用品托盘和重复示意物。腕骨携带及桌面复位为程序控制，握笔、夹持、书写和碰撞仍待画面与专业教师审查；书写不产生实际笔迹，也不作为临床记录技能评分。
