# 动小学 · 足踝评估诊室 v8

更新：2026-10-18，研发与课程提供者：张积众。

本版是在原完整净化迁移网站内新增的实时三维互动病例。保留首页、课堂登记、数字助教、骨肌拼接、课程页面、13实验导航、静态解剖资产以及旧四例接诊入口。首页“临床接诊”进入新的主线病例；旧四例仍可从新诊室菜单访问。

这是净化迁移与教学制作版，尚未通过临床运动学验证、专家逐项签审或真实教学效果评价，不能视为国家申报成品。技术检查不等于医学准确性验证。

## 运行

完整解压，双击 preview.cmd，或使用 Python 3.10+：

```
python serve_lab.py --port 8774
```

首页：http://localhost:8774/ 。新诊室：http://localhost:8774/clinic3d/index.html?demo=1 。启动器默认端口可能为8771，新诊室同样位于该端口的 /clinic3d/index.html?demo=1 。需要WebGL与支持importmap的现代浏览器，通过本地服务访问，不直接双击HTML。

姓名/学号/教师为课堂登记，不是学校身份认证。教师链接和临时访问码仅在本机服务启动窗口显示；数据库默认保存在站点之外。未打包运行数据库、访问码、密钥或浏览器记录。静态服务也能预览，但学习事件仅存本机并可导出。

## 本轮已实现

- 4.5×6×2.8m原创三维诊室、患者与治疗师两个独立骨架人物。接诊行走、落座、交谈姿态连续过渡；可切第三视角、治疗师视角和足踝近景。
- 一个虚构慢性踝关节不稳主线：六幕与复盘，共41个对话/操作/终结节点，包含正常路线和安全、拒绝、不适退出分支。
- 量角器参考标志核对、有效试次判断、受控步态事件标记、合成足压与COP判读、平衡条件核对、证据与计划对应。
- 步态角色与事件面板共用编排相位，播放/暂停/拖动和换机位保持同一时刻。相位0.08/0.62仅属此段示意，不是正常步态阈值。
- 已选分支持久化锁定；刷新继续不能改写选择。章节仅显示进度，完整回看在接诊记录。完成保存有幂等保护。
- 仅记录实际取得的病例资料、学习选择、未做项目与停止原因。可本机保存/恢复/导出；同源serve_lab接收 clinic3d_* 过程事件。旧教师面板可查看原始事件，尚未新增v8专用覆盖率或临床技能成绩。

## 制作范围与待办

人物是通用蒙皮模型，不是真人写实数字分身。当前有连续接诊过场和受控步态示意；检查量角器、膝触墙与平衡主要依靠教学示意和条件判读。真实手部接触、徒手检查、足弓形变、可靠关节轴配准、单脚保护与完整检查动作仍须逐项制作和专业签审。跨区域采用机位与人物布置切换，尚不是完整无剪切的临床动作长镜头。

足压视图是本地合成教学字段，无kPa/N或真实患者测量含义。既有 pressure/ 模块另保留明确许可的研究样例，不与新病例合成字段混称。低足弓是病例逐步讨论的相关发现，不预设为反复扭伤的唯一病因。不把骨架转角当患者角度，不从足压反推出肌力或韧带力。

本轮HeyGen制作、上传、配音任务数为0，未由本轮调用消耗其制作额度。可选浏览器朗读不是精确口型同步。
