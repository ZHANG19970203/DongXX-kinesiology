## 本轮调整

- 对话在左侧逐句显示；保留接诊与结束的礼貌，中段缩短。动小助在关键步骤说明先操作什么、完成后从哪里继续。
- 男治疗师保持深蓝上下装与鞋；女患者坐位依次脱鞋、脱袜后赤足检查。该过程为有限教学动画，尚无真实指尖抓握、袜口翻卷、织物与皮肤碰撞仿真。
- 墙面替换为3张真实解剖网格渲染：人体骨与关节、骨骼肌前后观、小腿与足踝骨肌。来源与逐图网格ID／哈希见 `clinic3d/docs/v12-anatomy-posters.json`。
- 患者保持赤足，按自然步幅走过5块连续压力板，不凑步踩板。步态事件与脚下足压使用同一教学时钟；各足在接触时显示压力中心，离地后不显示该足COP。
- 足压分为静态站立、行走瞬时帧和峰值合成图。静态站立足不前进，仅演示小范围COP摆动；峰值合成图不显示虚构的瞬时COP。

## 保留的学习功能

量角器对线与试次判断，踝关节背屈／跖屈和内翻／外翻滑块，近似运动轴与运动面，28骨与7肌肉的授权结构观察，以及患健侧步态、步长、步宽、步速、支撑期／摆动期比较继续保留。肌肉用于中立位静态观察，不计算肌力、肌肉激活或真实关节动力学。

器材架含原创壶铃、六角哑铃、筋膜球／按摩球、弹力带和足踝教具；电脑朝向治疗师。人物仍是可替换的虚构三维角色，当前外观不代表真人扫描或临床校准身体。

## 数据含义

步态参数与足压为原创虚构教学设定，未接入传感器。周期1.20s，右支撑56%、左64%；右步长0.48m、左0.40m、跨步长0.88m、步宽0.14m；步速约0.73m/s、步频100步／分。它们不是患者实测、正常阈值或慢性踝关节不稳的统一模式。步长以本次落地足命名，不能直接据长短判断优劣。

足压颜色使用固定相对色标，没有临床kPa／N含义。COP由当前非负接触载荷加权计算；双支撑时总COP与各足内COP是不同信息。峰值合成图各格点可能在不同时刻达到峰值，不能当作同一时刻的数据计算COP。

压力中心COP不是身体重心／全身COM；角色骨盆参考点也不是全身COM。本版没有进行分段质量加权的全身质心计算。低足弓条件中的中足接触变化仅供教学，不能由一个足印确诊扁平足或认定其是反复崴脚的唯一病因。独立公开研究样例保留来源，未冒称陈女士的实测记录。

## 运行与核验

完整解压后双击 `preview.cmd`；也可用Python 3.10+运行 `python serve_lab.py --port 8774`。通过本地服务器访问：

- 主线：`http://localhost:8774/clinic3d/index.html?demo=1`
- 解剖教具：`http://localhost:8774/clinic3d/anatomy.html`
- 人物预览：`http://localhost:8774/clinic3d/characters.html`

若启动器使用8771，相应替换端口。课堂登记不是学校身份认证。学习记录可本机保存、恢复、导出及交由同源课堂服务接收；数据库在站点外，不随ZIP分发，记录不等于临床技能成绩。

最终技术核验见 `VALIDATION_REPORT.md`；本轮分项证据见 `clinic3d/docs/validation-v12.md`。`file-manifest.json`记录逐文件字节与SHA256，自身除外。专业缺口、动作与教学审查项见 `clinic3d/docs/teacher-review-v12.md`，由教师逐项签审。
