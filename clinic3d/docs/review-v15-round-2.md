# 第2轮：医学概念与来源核对

执行时间：2026-10-18T16:49:37+08:00。本轮在第1轮15.0.1修订稿上继续审查，不是平行生成四份通过报告。

本轮实际web打开并读取出版方[JEB原始研究](https://doi.org/10.1242/jeb.02584)、[NHS足形资料](https://www.nhs.uk/conditions/flat-feet/)、[MRC官方原始检查手册](https://www.ukri.org/wp-content/uploads/2021/12/MRC-011221-AidsToTheExaminationOfThePeripheralNervousSystem.pdf)和[novel官方操作资料](https://novel.de/support/emed-support/)；同时核对[APTA/JOSPT临床指南官方索引](https://www.jospt.org/doi/10.2519/jospt.2021.0302)。其余源记录与第14版已核对的原始研究／官方资料逐题对应，访问边界仍见v14来源文件；不把只读到索引的来源声称为本轮阅读全文。

发现与处理：

1. **O5-Q2缺少环境和对象限定。**初版只说“步态机制”，容易被推广到坡地、跑步或所有病理步态。JEB原始研究明确平地与坡度可改变质心时序；现将题干限定“常见平地成人参考”，正确选项加“通常”与“末支撑至预摆”，解释说明本程序未测全身COM／肌电。
2. **O6-Q2的MPP概念原引文不够直接。**原有足压与站立论文不能单独承担MPP展示形式的来源。现加入novel一手官方操作资料，核对其将Maximum Pressure Picture与逐帧roll-over分开。该来源只支持操作／图形含义，不用作诊断或疗效证明；“不同格点峰值不一定同时”是对当前逐点取峰值定义的数学解释，不冒称厂商验证了本合成模型。
3. **低足弓因果、MMT、平衡推断保留限制。**NHS资料说明低足弓可无症状；MRC原始手册区分重力／抗阻的0—5临床分级；CAI指南要求综合评估。题目均没有把足形、肌力等级或闭眼表现提升成唯一病因、精确力矩或神经损伤定位。
4. **保留“没有测得”的边界。**质心、COP、肌电、韧带张力分别表述；压力非均匀并不自动异常，固定S形不作通用阈值。第3轮继续专门查病例数值、量表和评价口径，尤其对照资料的来源标识。

来源使用范围：正常关节／测法依据为官方解剖与原始方法研究；临床推理依据为协会指南／NHS；MPP资料仅是官方一手格式说明。本轮未复制图像、研究数值、患者信号或长段原文。
