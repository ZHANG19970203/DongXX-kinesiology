交付日期：2026-10-18（Asia/Shanghai）。研发者与课程提供者：张积众。

本版在已净化的v3上加入足踝病例接诊、本机学习过程采集和教师看板。用于教师审查及课程试用，尚未经过临床运动学验证、病例专家签核、真实教学效果评价或国家级申报验收，不能视为国家申报成品。教学实验不一概要求自行购买设备或采集人体数据，所需验证应与具体功能承诺及申报批次匹配。

## 打开与运行

完整解压后双击 `preview.cmd`，或使用 Python 3.10+ 运行：

```
python serve_lab.py
```

学生首页 `http://127.0.0.1:8771/`，诊室 `http://127.0.0.1:8771/clinic/?demo=1`。教师专用链接与临时访问码在启动窗口显示；链接使用地址片段传递令牌。学习数据库保存在站点目录之外，默认本机用户应用数据目录 `DongXueXiaoLab/learning.sqlite3`；可用 `--data-dir` 指定站外目录。服务只绑定本机地址，不向局域网或公网开放。

首页姓名、学号和教师姓名仅为课堂登记，任课教师填写“张积众”；不是学校身份认证。访客演示不会伪装为已登记学生。教师访问码保护本机记录读取，不是学校权限系统。原纯静态模式 `python start_local.py` 仍可用，但不提供采集接口，诊室会保留待上传记录并可导出。

## 本次可操作的接诊

- 四例原创虚构教学病例：扁平足、高足弓、踝扭伤恢复期、慢性踝关节不稳。
- 问诊按症状、病史、功能、目标与安全分组，患者逐步披露固定事实；自由追问匹配已有病例问题，重复问诊不重复计入覆盖项。
- 检查先听取患者顾虑，再说明目的及边界、取得配合、查看教学资料；不适合的选项提供理由反馈。
- 标记病例资料、文献依据和独立公开读图练习；选择解释与复评计划，填写开放总结，保存和导出过程。
- 原创AI生成的虚拟患者场景立绘，属于图像表现，不是三维角色、真人视频、动作捕捉或病例本人影像。语音为主动开启的设备朗读，可用性取决于浏览器和本机音色，没有口型同步。

病例历史、症状与检查结果是原创教学设定，不是真实患者记录。足型不自动等于疾病，足压不单独作诊断或回归运动决定。病例专业要点、引用与待核查事项见 `clinic/CASE_REVIEW.html`，尚未完成临床专家签核。未获得这四类病例的真实连续足压，当前没有根据疾病名称生成假压力曲线。

## 学习过程与教师看板

诊室向同源 `/api/learning/events` 提交会话与事件，接收端以事件ID幂等保存。问诊、自由追问、检查前沟通、选择、证据、解释、计划与完成总结可供回看。数据库位于站点之外，不随ZIP分发。失败记录在浏览器保留待传队列，重试不会重复计数；不能把上传失败写成已到达教师端。

教师通过专用入口查看实际收到的会话、完成情况、关键问诊覆盖、操作时间线、对话和开放总结，可导出。页面没有预置假学生或假使用量。覆盖率是问诊项目覆盖，不等同临床能力、文本正确性或技能总分；不推断注意力、情绪、心理特征，没有采集摄像头或麦克风音视频。

首页合并JSON/HTML继续保留原课程、拼接、专题和足压记录，并加入当前学生已完成病例接诊。历史v3导出和服务器记录分开保留，原模块未被冒称已经全部接入服务器。

## DeepSeek适配与离线模式

服务端 `ai_adapter.py` 提供可配置的语义匹配适配。只有设置服务环境 `DEEPSEEK_API_KEY` 后才尝试外部调用，模型可通过 `DEEPSEEK_MODEL` 配置。未配置时用本地规则匹配固定病例资料；外部错误或非法结果时回退。密钥不进入学生网页、静态文件、学习事件或发布包。

模型只从已编写的问题ID中选择匹配项，患者回答始终来自病例原文；不让模型生成新的损伤等级、检查结果、压力数据或治疗处方。不向模型发送学生身份或完整学习记录。无法匹配时请学生澄清，而不是凭空补充病史。

API形式依据 [DeepSeek官方首次调用文档](https://api-docs.deepseek.com/quick_start/agent_integrations/) 及 [JSON Output文档](https://api-docs.deepseek.com/guides/json_mode/)。2026-10-18核对的默认模型名称为 `deepseek-flash`，部署时应按账户可用模型复核。本轮只验证离线与模拟服务响应，未持有或使用真实服务凭据，未完成在线DeepSeek连接验证。配置存在不等于连接已经通过。
