## 本次体验升级：为什么测、怎样动手、如何解释

研究问题：最高一个测点的读数降低了，是否能说明整只鞋垫的读数都降低了？单看脚在动或单看一个峰值，都不能回答读数在足底怎样分布、加权中心怎样变化。本实验让学生通过多点记录建立证据。

首屏改为可旋转、缩放、点选的原创三维数据实验台，带空间网格、台面、32个传感单元、数据柱及来源CoP。支持斜视、俯视、侧视、复位和全屏；二维数据与完整数值核对继续保留。三维柱高与颜色只是原始通道值的显示映射，没有足骨配准，也不表示组织凸起或物理高度。

任务依次为：

1. **先预测**：观察左足第25与50帧的分布，CoP暂隐藏，提交方向预测或“暂不能判断”。预测错误不记作能力不足。
2. **找证据**：点选两帧各自最高传感器，分别标记原值、sumP、CoP与阈值；两帧使用同一片段固定色标和相同筛选阈值。可在三维场景点击，也可用完整读数表选点。
3. **解释并保存**：比较最高单点、总和与CoP；概念选择得到反馈，观察和开放解释交教师审阅。保存预测、选点尝试、两帧快照及过程，并随HTML/JSON导出。

本例第25帧峰值#27=2781，第50帧#8=2312；总和却由20935升至24620，CoP的y由423.67降至161.01，表示在来源图纸坐标中移向趾端。这是有来源的“单点与整体分布”反例，不用最高点替代CoP，不把CoP当作全身质心。教学假设另由 `pressure/tools/check_inquiry_case.py` 核对原CSV。

## 足底压力案例的来源和解释边界

采用 [Insole-GAITRite 官方数据发布](https://zenodo.org/records/19662017)，DOI [10.5281/zenodo.19662017](https://doi.org/10.5281/zenodo.19662017)，版本1，CC BY 4.0。作者署名、原发布CSV/SVG、许可记录快照与逐文件哈希见 `pressure/licenses/`。本包仅裁选一个研究片段，保留原始32通道、sumP和copX/copY，转换为便于浏览器读取的JSON；没有引入GaitScope应用程序代码。

每个色点表示一个离散传感通道，并非连续足底压力场。原始读数未提供本包可核验的kPa/N标定；坐标为来源CoP使用的图纸坐标，不是厘米/毫米。鞋垫名义采样率64Hz，显示时间为行号/64估计，不是CSV采集时间戳。左右足独立观察，不把相同行号自动视为严格同步。

调节通道总和阈值仅筛选观察帧，低值处轨迹断开；它不自动识别足跟着地、足尖离地或完整支撑期。A/B比较限同一足同一片段的两个时刻，不能当作不同步速、鞋垫干预或患者治疗效果。播放速度只控制观看速度，不生成另一种真实步速的数据。

可学习：读图、比较通道值、区分单脚压力中心与全身质心、识别阈值选择对轨迹的影响、区分观察和解释。当前不计算临床足弓指数、物理压力、物理轨迹长度、步长、真实速度、异常步态分类或设备实时读数。

原LTM-ZDYL-200彩页/PPT仅作能力说明审阅；未获得设备原始连续数据或接口，也没有将厂商截图作为本包可分发资产。CAD WALK等其他资料未混入当前案例。
