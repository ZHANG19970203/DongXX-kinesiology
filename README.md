# 动小学 v25：肌肉彩绘、自由探索与学习荣誉

2026-10-27。基于已存在的 v24 完整网站继续开发，保留足踝诊室、SOAP、13实验、骨肌拼接、统一助教及教师私有记录。

## 开始使用

本机原入口 http://127.0.0.1:8784/ 已切换到此版。首页备学区新增“肌肉彩绘”。也可打开 `/painting/`、`/certificate/`；教师从 `/teacher/login.html` 登录，学习总看板有“彩绘与证书”入口。网站需要Python服务器，不能双击HTML来代替后台。

## 肌肉彩绘

- 23组、64学习项；59项具备真实肌肉网格和左右侧投影，5项暂为知识学习。按截图目录及本机部分课程片头核对名称。第22讲第三块是腘肌。
- 完整人体体表与肌肉来自同一BodyParts3D解剖坐标。学生可以选肌肉、侧别、放大、绘画、擦除、撤销、重画。
- 服务器根据原始笔迹计算：覆盖率≥70%且外溢率≤25%通过，显现该肌肉的可旋转三维模型。交并比单独显示，不把70%称为临床准确率。
- 查看参考也可学习，单独标为参考后练习；参考本身不算通过。完成彩绘后再辨认作用，保存学习完成。
- 深层和部分遮盖肌标为投影学习，不能当成直接可见、可触诊的边界。完整肌肉投影包含附着与肌腱走向，不等于肌腹体表测量标准。尚无专家标定的关键点分数。
- 背阔肌、腹直肌、腹内斜肌、腹横肌、腰方肌在当前取得的授权数据中缺项；保留其起止点与作用学习，不虚构网格。

## 自由学习与返回

诊室对白提到肌肉、关节、足弓、步态、COP或证据时，出现可忽略的动小助泡泡。可打开已有三维概念面板、相关彩绘或13实验，主诊室暂停。关闭学习窗口后返回原对话节点。跳步仍保留既有未检查状态。不会把打开提示直接计为完成。

## 体验完成证书

落款“动小学”，含学生姓名、完成范围、编号、签发日期和学习清单，可下载HTML证书与报告，或打印保存PDF。

- 足踝诊室：8项体验，包括问诊/安全、足弓、肌群、关节、足压、平衡、步态、证据与反思；或完整提交既有SOAP路径。
- 13实验：每项保存一次观察和一段解释。
- 彩绘：59项至少一侧通过彩绘并辨认功能，加5项缺模型肌肉的知识辨认。
- 全课程：以上85项全部完成。各单独路径也可领取注明该路径的证书。

未达100%不能由服务器签发；预览有“尚未签发”水印。同一学生、范围与规则版本重复领取复用编号。体验完成和知识成绩分开记录；这是学习纪念证书，不是临床能力、学历或执业认证。旧版诊室/13实验操作事件属于教学过程记录，并非防作弊考试成绩。

## 教师数据与环境

沿用私有SQLite数据库、026870教师账户和个人密码机制。新增原始笔迹、判分、参考使用、功能练习、自由学习进出和证书证据。教师Excel现在有10个工作表，新增“肌肉彩绘”“学习证书”。更新网站不清空历史数据。

当前仍为本机储存，未部署云端；全班跨设备集中收集需要后续学校服务器部署。清除浏览器数据会丢失当前浏览器的个人入口凭据；服务器历史仍在教师数据库。备份和密钥均在站点外，ZIP不包含学生记录、API密钥或首次设置文件。

新增依赖Pillow，用于服务器重算笔迹。运行Python 3.9+并安装Pillow；本机已具备。Excel继续使用现有Node与@oai/artifact-tool。此轮没有新增HeyGen制作或付费模型调用。
